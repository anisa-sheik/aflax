# Daily Devotion Hub

BUILD A REAL MOBILE-FIRST APPLICATION (NOT A WEBSITE)

IMPORTANT RULE:

This must be built as a REAL APPLICATION UI/UX — NOT a website.

Reject any design that looks like:

Landing pages

Marketing pages

Scroll-based websites

Blog-style layouts

Instead build:

App-style interface (like iOS/Android apps)

Native mobile app feel

Full-screen navigation

Tab-based structure

No “homepage marketing sections”

APP TYPE

This is a PRODUCTIVITY MOBILE APPLICATION (not a website).

Think:

Notion mobile app

Duolingo app

Apple Health app

Muslim Pro app

Linear app

NOT:

SaaS marketing website

Company homepage

Landing page funnel

UI/UX REQUIREMENTS (CRITICAL)

1. APP STRUCTURE

Use APP NAVIGATION ONLY:

Bottom tab bar (mobile-first)

Home

Prayer

Quran

Tracker

Profile

OR side drawer navigation on desktop.

NO top navigation website menus.

NO landing pages.

2. HOME SCREEN (APP DASHBOARD)

Must be a full-screen app dashboard:

Next prayer (big focus card)

Countdown timer

Today’s progress

Streaks

Quick actions buttons

Design must feel like a mobile app home screen.

3. DESIGN STYLE

Must look like a modern native app:

iOS / Android UI style

Card-based layout

Rounded corners

Soft shadows

Minimal text

Large touch targets

Bottom navigation bar

NO website hero sections.
NO marketing banners.
NO pricing pages.

4. USER EXPERIENCE

Must behave like an app:

Instant navigation (no page reload feel)

Smooth transitions

Persistent bottom navigation

Swipe-friendly layouts

Modal sheets instead of pages where possible

5. RESPONSIVE RULE

Mobile is PRIMARY.

Desktop is secondary and should behave like:

Centered app window

NOT a stretched website layout

FUNCTIONAL REQUIREMENTS

Everything must still be a real web application:

Real authentication (Supabase)

Real database persistence

Real user data

Real CRUD operations

But UI must feel like a mobile app.

DATABASE RULES

Same as production app:

Users

Prayer tracking

Quran progress

Dhikr sessions

Goals

Journal entries

NO mock data.

FORBIDDEN UI PATTERNS

DO NOT generate:

Landing pages

Hero sections

Marketing copy sections

“Features overview” pages

Blog-style layouts

Pricing pages

Company pages

REQUIRED OUTPUT STYLE

Every screen must look like:

✔ Mobile app screen
✔ Full-height UI
✔ Navigation-driven
✔ Action-focused
✔ Minimal text
✔ Functional-first design

NOT like a website.

FINAL GOAL

Create a REAL MOBILE APPLICATION EXPERIENCE inside a web app:

A user should feel like they installed an app from App Store / Play Store.

NOT like they opened a website in a browser.
